# mapping-plus

「マッピング」の `.mapping` バックアップをパソコンで閲覧し、GPSの位置飛びなど不要な記録を削除して保存できる非公式Webツールです。

**公開ページ:** [https://minoru-s.github.io/mapping-plus/](https://minoru-s.github.io/mapping-plus/)

## 主な機能

- `.mapping` バックアップのGPSヒートマップ表示
- セルごとの記録回数・初回／最終訪問日時の表示
- 訪問回数の多いセルのランキングと、該当セルへの地図移動
- 訪問済みセル数・延べ記録回数・記録期間・埋めた面積の集計
- 埋めた面積と日本の市区町村面積との比較
- 地図のパン・ズームに追従する軌跡表示
- 消しゴムによる不要な記録の削除
- Undo／Redo
- 本家アプリと互換性のある `.mapping` 形式での再保存
- ファイルをサーバーへ送信しない、ブラウザ内でのローカル処理

## 使い方

1. `.mapping` ファイルを選択するか、画面へドラッグ＆ドロップします。
2. 通常時はドラッグで地図を移動し、ホイールやトラックパッドで拡大・縮小します。色の付いたセルをクリックすると、そのセルの記録回数と初回・最終訪問日時を確認できます。
3. 「統計」から、訪問セルランキングと全体統計を確認できます。ランキングの項目を押すと、そのセルへ移動します。
4. Zoom 10以上で「消しゴム」を選び、不要な軌跡上をドラッグします。Zoom 10〜12では広い範囲を消しやすいため、細かな修正にはZoom 16を推奨します。
5. Undo／Redoで内容を確認します。
6. 「編集済みファイルを保存」を押します。`YYYYMMDD-HHmmss.mapping` という名前で新しいファイルがダウンロードされます。

読み込んだ元ファイルを上書き・削除する処理はありません。編集結果は必ず別ファイルとして保存されます。動作確認が済むまでは元ファイルも保管してください。

消しゴムは、記録点ではなく内部の最小セル単位で削除します。Zoom 16ではおよそ20m四方で、同じセル内に複数回の記録がある場合はまとめて削除されます。

## 動作環境

マウスまたはトラックパッドを備えた、モダンなデスクトップブラウザを想定しています。スマートフォンでは閲覧できる場合がありますが、編集操作とファイル保存は動作保証外です。

ライブラリと背景地図を取得するため、利用時にはインターネット接続が必要です。ただし、`.mapping` ファイルとGPS記録そのものはブラウザ内で処理され、サーバーへアップロードされません。

ランキングの都道府県・市区町村名は、同梱した行政区域データをブラウザ内で照合して表示します。GPS座標を外部の逆ジオコーディングAPIへ問い合わせることはありません。

利用状況の把握にはGoogle Analyticsを使用しており、ページの閲覧情報がGoogleへ送信される場合があります。`.mapping` ファイルやGPS記録がAnalyticsを通じて送信されることはありません。

## ローカルで起動する

ビルドは不要です。リポジトリのディレクトリでHTTPサーバーを起動し、表示されたURLをブラウザで開きます。

```bash
python3 -m http.server 8000
```

## 使用ライブラリ・地図

- [Leaflet](https://leafletjs.com/)
- [JSZip](https://stuk.github.io/jszip/)
- [sql.js](https://sql.js.org/)
- [OpenStreetMap](https://www.openstreetmap.org/)
- [CARTO](https://carto.com/attributions)

市区町村との面積比較には、国土地理院「令和8年全国都道府県市区町村別面積調」（2026年4月1日時点）を使用しています。

ランキングの地域判定には、国土交通省「国土数値情報（行政区域データ）」（2026年1月1日時点）を簡略化した境界データを使用しています。加工方法とライセンスは [`data/README.md`](data/README.md) を参照してください。
